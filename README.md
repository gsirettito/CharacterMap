# CharacterMap 🗺️

> Una aplicación de escritorio para explorar y visualizar los caracteres de las fuentes instaladas en Windows.

## 📋 Descripción

**CharacterMap** es una herramienta ligera desarrollada en **WPF** que permite a los usuarios:

- Navegar por las familias de fuentes disponibles en el sistema.
- Visualizar todos los glifos (caracteres) que incluye cada fuente.
- Copiar caracteres al portapapeles para usarlos en otros programas.

Ideal para diseñadores, desarrolladores o cualquier persona que necesite consultar rápidamente qué caracteres incluye una tipografía.

## ✨ Características

- 🖥️ Interfaz nativa de Windows (WPF).
- 🔍 Listado completo de fuentes del sistema.
- 🔤 Visualización de glifos por familia tipográfica.
- 📋 Copia de caracteres al portapapeles.
- ⚡ Carga rápida y rendimiento optimizado gracias al uso de `VirtualizingWrapPanel`.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** C#
- **Framework:** .NET (WPF)
- **IDE recomendado:** Visual Studio 2022 o superior
- **Arquitectura:** MVVM (Model-View-ViewModel)

## 📦 Requisitos

- Windows 10 / 11
- .NET Framework (o .NET Desktop Runtime, según la versión del proyecto)
- Visual Studio (para compilar desde el código fuente)
